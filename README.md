# ibda-saba

نظام صرافة ومحاسبة متكامل لإبداع سبأ.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح:
- http://localhost:3000

## الصفحات المتاحة

- لوحة التحكم
- تسجيل الدخول
- العملاء
- الصناديق
- السندات
- الحوالات
- التقارير
- المستخدمون
- الإعدادات

## ملاحظة

هذا هو نموذج واجهة Frontend عملي وقابل للتشغيل محلياً، مصمم للعرض والتجربة. للوظائف المحاسبية الحقيقية، يلزم طبقة Backend حقيقية وقاعدة بيانات PostgreSQL/Prisma.
